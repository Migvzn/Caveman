## 1️⃣ Construire le site avec Base44

1. Ouvre `1-SITE-BASE44/PROMPT-BASE44-VAYNORA-HOUSE.txt`, **sélectionne tout, copie**.
2. Crée une nouvelle app sur Base44 et **colle le prompt entier**.
3. Si Base44 ne construit pas tout d'un coup (projet très complet), écris simplement :
   `Continue : construis les éléments manquants du cahier des charges, section par section, sans casser l'existant.`
4. Le prompt crée déjà toute la **structure de l'Académie** : les 19 modules, les 141 titres de leçons et les 6 parcours. La page publique `/academie` affiche le programme complet.

> Si Base44 refuse un texte aussi long ou si le résultat est incomplet, utilise `option-prompts-par-phases.md` (14 prompts plus courts, à coller l'un après l'autre).

## 2️⃣ Mettre la formation OFM sur le site

Une fois le site construit :
1. Va dans **Espace privé → Académie → Admin → Import**.
2. Ouvre `2-FORMATION-OFM/FORMATION-OFM-VAYNORA-HOUSE.md` (ou les fichiers de `modules/`).
3. Copie **un module à la fois** (depuis la ligne « # Module N — … » jusqu'à la ligne juste avant le module suivant), colle-le, coche **« Remplacer le module existant »**, importe.
4. Répète pour les 19 modules (00 → 18). Les leçons, encadrés « À retenir » et quiz sont créés automatiquement.
